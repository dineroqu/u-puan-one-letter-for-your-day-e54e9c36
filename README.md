One letter for your day: **K**, for **knackered** — British slang for utterly
done-in, body and brain spent. One word paints the whole picture: flat on
the sofa, good for nothing. The program scores eight candidate day-words
against the judge's five criteria (vivid, funny, true, fitting initial,
with an obviousness penalty for the sponsor's own printed example Z) and
writes the winner — K — as a single byte to `/output/entry.txt`. Blunt
slang that lands at once, true of everyone's worst days, and not the
obvious pick every other entrant reaches for first.

## Run it

```sh
python3 main.py
```

It writes exactly `K` (one byte, no newline) to `/output/entry.txt`.
