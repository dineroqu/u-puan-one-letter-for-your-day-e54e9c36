One letter for a knackered day. The entry is a single character — **K** — standing for the word that describes the day: *knackered*, flat-out done-in, body and brain spent. The program scores a shortlist of candidate letters against the judge's own five criteria (a real day-word, vivid, funny, true, a fitting initial) and writes the winner to `/output/entry.txt`. K wins because it paints the whole picture in one word instead of a vague mood, lands at once as blunt slang, is true of everyone's worst days, and is not the obvious pick — A, F and Z are the letters every entrant reaches for first. The scoring, with the obviousness penalty for the sponsor's own example letter, lives in `main.py`.

## Run it

```sh
python3 main.py
```

That writes exactly one byte, `K`, to `/output/entry.txt` — no word, no gloss, no punctuation, no newline. Run it twice and the output is byte-identical.
